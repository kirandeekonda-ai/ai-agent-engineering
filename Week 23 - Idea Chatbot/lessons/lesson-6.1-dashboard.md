# Module 6, Lesson 6.1: Idea Dashboard

## 🎯 What We're Building

A **beautiful dashboard** to view all saved ideas with:
- Card-based grid layout
- Key metrics (title, domain, time/cost estimates, complexity)
- Status badges (pending, in-progress, completed)
- Search and filtering
- Responsive design

## 🎨 Dashboard Features

### 1. Overview Stats
- Total ideas submitted
- Ideas by status
- Ideas by domain

### 2. Idea Cards
Each card shows:
- 💡 Title
- 📝 Description (truncated)
- 🏢 Domain badge
- ⏱️ Time estimate
- 💰 Cost estimate
- 🎯 Complexity level
- 📅 Created date
- ✅ Status

### 3. Interactivity
- Click card to see full details
- Filter by domain/status
- Search by title/description
- Sort by date/complexity
